# MadKicks 👟

> A Jamaican e-commerce storefront specializing in shoe reselling, sneaker culture, and localized shopping experiences.

## Tech Stack & Architecture
- **Frontend:** Next.js / React (Hosted on Vercel)
- **Backend:** Node.js / Express REST API (Hosted on Render)
- **Database:** PostgreSQL (Hosted on Neon.tech)
- **Mailing:** Resend (`jahwebproductions+madkicks@gmail.com`)
- **DevOps:** Docker, Docker Compose, Git

## Local Setup
1. Clone the repository
2. Run `npm install` (or `pnpm install`)
3. Copy `.env.example` to `.env` and fill in credentials
4. Run `docker-compose up` or start local dev servers
